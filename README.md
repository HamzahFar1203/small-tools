<h2>Project Summary</h2>
Small Tools is an ongoing project. The purpose of small tools is to provide users with tools to accomplish their everyday tasks. As I work on other projects, such as the to-do-list app, I may take from those projects and add to Small Tools. Years ago, I began this project as a means to test my web development skills as well as create tools that would be useful for me during the school year. Originally, I used Bootstrap to style the HTML elements, but with this recent commit, I've switched entirely to my own custom-written CSS. This was a personal decision because I prefer having complete control and flexibility over the styling and placement of my UI elements.
